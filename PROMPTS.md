Prompts utilizados no desenvolvimento — Semana Acadêmica FEPI 2026
1. Desenvolvimento do projeto

Utilização de Inteligência Artificial como ferramenta de apoio na criação e desenvolvimento do site da Semana Acadêmica FEPI 2026.

2. Prompts utilizados
Prompt 1 — Estrutura inicial

Solicitação de auxílio para desenvolver a estrutura inicial de uma página web utilizando HTML e CSS para apresentar a Semana Acadêmica FEPI 2026.

Prompt 2 — Identidade visual

Solicitação de auxílio para organizar o layout, cores, tipografia e elementos visuais do site, seguindo a identidade institucional da FEPI.

Prompt 3 — Programação

Solicitação de auxílio na implementação e organização dos códigos HTML e CSS, incluindo menus, seções e botões de navegação.

Prompt 4 — Funcionalidades

Solicitação de auxílio para implementar funcionalidades da página, incluindo botões e formulário de inscrição.

Prompt 5 — Correções e melhorias

Solicitação de auxílio para identificar problemas, corrigir erros e melhorar a organização e formatação do código.

3. Ferramentas utilizadas
Visual Studio Code.
HTML.
CSS.
Inteligência Artificial como ferramenta de apoio ao desenvolvimento.
4. Considerações finais

A Inteligência Artificial foi utilizada como apoio durante o desenvolvimento do projeto, contribuindo para a estruturação, implementação, correção e melhoria do site da Semana Acadêmica FEPI 2026.
